## 📌 About the Project

This repository contains my personal web developer portfolio. It
introduces me as a BCA student and aspiring web developer, and brings
together my profile, interests, sample projects, learning progress,
resume link, and contact information in one place.

The website is built with plain HTML, CSS, and vanilla JavaScript. It
uses a soft pastel visual theme, responsive layouts, and lightweight
animations to create a friendly browsing experience.

## ✨ Features

-   **Personal hero section** -- introduction, profile photo, and calls
    to action.
-   **Typing animation** -- cycles through role descriptions such as Web
    Developer and Creative Designer.
-   **Responsive navigation** -- collapsible menu for smaller screens.
-   **About and services section** -- highlights the type of web work I
    enjoy.
-   **Projects section** -- showcases portfolio and landing-page project
    cards.
-   **Skills section** -- displays the technologies and design skills I
    am currently developing.
-   **Scroll reveal effects** -- sections animate into view as the
    visitor scrolls.
-   **Animated skill bars** -- skill indicators animate when the skills
    section becomes visible.
-   **Interactive portrait** -- subtle pointer-based tilt effect on
    supported desktop devices.
-   **Scroll progress indicator** -- shows the visitor's progress
    through the page.
-   **Resume download link** -- provides access to the resume PDF.
-   **Contact section** -- includes email, location, phone, and GitHub
    details.
-   **Reduced-motion support** -- respects the visitor's
    operating-system motion preference.

## 📁 Project Structure

Keep the following files together in the project root so the relative
asset paths in `index.html` work correctly:

``` text
My-Portfolio/
├── index.html       # Main portfolio page
├── style.css        # Styling, responsive layout, and animations
├── script.js        # Interactive behaviour and effects
├── myphoto.jpg      # Profile photo
├── resume.pdf       # Downloadable resume
└── README.md        # Project documentation
```

> **Important:** The HTML currently refers to the exact filenames
> `style.css`, `script.js`, `myphoto.jpg`, and `resume.pdf`. Make sure
> the files in your GitHub repository use those names, or update the
> paths in `index.html` to match your filenames. File names are
> case-sensitive on many hosting services.

## 🚀 Run Locally

You can run this project without installing dependencies.

1.  Clone the repository:

    ``` bash
    git clone https://github.com/muskanwebdev/My-Portfolio.git
    ```

2.  Open the project folder:

    ``` bash
    cd My-Portfolio
    ```

3.  Open `index.html` in your browser.

For a smoother development workflow, open the folder in **Visual Studio
Code** and use the **Live Server** extension to preview changes.

## ⚙️ Customize the Portfolio

-   **Name and introduction:** Edit the hero content in `index.html`.
-   **Profile picture:** Replace `myphoto.jpg` with your preferred
    image, keeping the same filename.
-   **Colors and appearance:** Update the CSS variables near the top of
    `style.css`.
-   **Typing animation:** Edit the `words` array in `script.js`.
-   **Projects:** Update the project cards with real project names,
    descriptions, and working links.
-   **Skills:** Update the skill labels and visual percentages in
    `index.html` to reflect your current abilities accurately.
-   **Resume:** Replace `resume.pdf` with your latest resume.
-   **Contact details:** Update the email, phone number, location, and
    GitHub link in `index.html`.

## 🌐 Deployment

This is a static website and can be hosted using GitHub Pages or another
static hosting provider.

For GitHub Pages:

1.  Open the repository on GitHub.
2.  Go to **Settings → Pages**.
3.  Under **Build and deployment**, choose **Deploy from a branch**.
4.  Select the branch containing your website (usually `main`) and the
    root (`/`) folder.
5.  Save the settings and wait for GitHub Pages to publish the site.

After publishing, GitHub will show the website URL in the Pages
settings.
