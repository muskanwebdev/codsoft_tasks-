# PNS — PixelNest Studio

A creative digital studio website concept focused on modern web design, brand identity, and user-friendly digital experiences.

> **Ideas brought to life.**

## About The Project

PNS (PixelNest Studio) is a creative digital studio website built using HTML, CSS, and JavaScript. It showcases modern design, creative ideas, and digital experiences through a clean and attractive interface.

The website is designed to present studio services, creative work concepts, and ways for visitors to connect with the studio.

## Features

- Modern and creative homepage
- Responsive navigation menu
- Animated gradient text and visual effects
- Creative About Us section
- Services section with four service categories
- Selected work and portfolio concepts
- Four-step working process
- Contact section with project enquiry form
- Feedback section with a five-star rating system
- Interactive buttons and navigation
- Modern typography using Google Fonts
- Attractive footer with social links

## Website Sections

1. **Home** — Introduction to PixelNest Studio.
2. **About Us** — Studio overview and creative approach.
3. **Services** — Web Design, Brand Identity, UI/UX Design, and Creative Solutions.
4. **Selected Work** — Mono Studio, Future Space, and Grow Collective concepts.
5. **Our Process** — Discover, Explore, Create, and Deliver.
6. **Let's Talk** — Call-to-action section.
7. **Contact** — Contact details and project enquiry form.
8. **Feedback** — User rating and feedback form.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts (DM Sans and Manrope)

## How to Run the Project

1. Download or clone the repository.
2. Open the PNS project folder.
3. Open `index.html` in your web browser.
4. You can also use the Live Server extension in Visual Studio Code.

## Customisation

You can customise this project by:

- Changing website text and content.
- Updating colours and styles in CSS.
- Adding new services and projects.
- Updating contact email and social media links.
- Improving animations and interactive features.

**Note:** The displayed portfolio work is presented as creative concepts. The contact email and Instagram links are demo placeholders and should be updated before using the website as a real business site.

## Project Purpose

This project demonstrates front-end web development skills and creative website design using core web technologies. It was created as a practical project to showcase design, layout, and interactive website development.
